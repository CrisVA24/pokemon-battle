# Pokémon Battle

Aplicación web de batalla entre dos Pokémon desarrollada con HTML, CSS y JavaScript.

El proyecto utiliza la PokéAPI para buscar Pokémon, cargar sus datos y crear una batalla sencilla entre dos luchadores.

## Funcionalidades

- Búsqueda de Pokémon con debounce.
- Sugerencias obtenidas a partir de PokéAPI.
- Selección de dos luchadores.
- Carga de sprite, HP y movimientos.
- Cuatro movimientos por Pokémon.
- Daño aleatorio.
- Actualización del HP durante la batalla.
- Detección del ganador.
- Reinicio de la batalla.
- Manejo de estados de carga y errores.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Fetch API
- PokéAPI
- Git
- GitHub

## API

El proyecto utiliza la API pública y gratuita de PokéAPI:

https://pokeapi.co/

No requiere API key ni backend.

## Cómo ejecutar

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir `index.html` en el navegador.
